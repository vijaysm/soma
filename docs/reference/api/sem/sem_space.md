# `soma/sem/sem_space.hpp`

`SemSpace`, `SemGeometry`: the spectral-element space of order p over quads in the plane or on a
sphere: GLL points per element, their geometry, direct stiffness summation (`dss`), the assembled
`mass` and exact `integral`s. See [spectral elements](../../../algorithms/spectral-elements.md).
