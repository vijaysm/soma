# `soma/testing/box_mesh.hpp`

`soma::testing::box_mesh`, `BoxSpec`, `BoxCounts`, `box_counts`: structured box meshes (hexes, tets,
quads, triangles) with closed-form counts, coordinates and orientation, for tests. See [building
meshes](../../../concepts/building-meshes.md).
